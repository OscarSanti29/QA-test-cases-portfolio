# Mealfinder - Manual Test Cases
Thi folder contains manual test cases created to validate the functionality, usability, and UI behavior of the FakeStore web application.

The purpose of these test cases is to demonstrate structured QA thinking, clear documentation, and coverage of core e-commerce user flows.

## Application Overview
**Application Type:** Web Application (E-commerce)
**Tech Stack:** React, Javascript, REST API
**Environment Tested:**
- OS: Windows 11
- Browser: Chrome (latest)


## Scope of Testing
The following functional areas are covered:

- Saved Local Storage
- Product Browsing & Search
- Product Filtering by Category
- UI / UX Validation


## Types of Testing Performed
- Smoke Testing
- Manual Functional Testing
- Exploratory Testing
- Basic Regression Testing
- UI Validation


## Test Case Structure
Each test case includes:
- Test Case ID
- Title / Description
- Preconditions (if applicable)
- Step-by-step execution steps
- Expected Results


## Notes
- These test cases were created as part of a QA portfolio project.
- The application under test is a demo project and may not reflect production-level stability.
- Test cases focus on clarity, coverage, and reproducibility rather than automation.
